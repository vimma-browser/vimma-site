Vimma is Firefox underneath, so your bookmarks, passwords and add-ons come along. A key in Vimma means one thing: where Firefox had a shortcut on a key Vim uses, such as ctrl+w or ctrl+d, Vimma switches Firefox's off, so you never close a tab when you meant to delete a word.

Bring your bookmarks and passwords

Vimma has a profile of its own, so nothing comes over from another browser until you bring it. Bookmarks, passwords and recent history move in a few minutes; add-ons are installed again.

  • From Firefox, with Sync. Sign in with the same Mozilla account in Firefox and in Vimma (:settings sync, then Sign in), and choose what to sync. Sync brings recent history, about the last 60 days.
  • From Firefox, with files. Bookmarks: export them to HTML from Firefox's Library (ctrl+shift+o, Import and Backup) and import the file from Vimma's. Passwords: about:logins, its … menu, Export Passwords in Firefox and Import from a File in Vimma. The exported file holds every password in plain text, so delete it afterwards.
  • From Chrome, Chromium, Brave, Edge, Opera or Vivaldi. :firefox cmd_file_importFromAnotherBrowser opens Firefox's import wizard; f on Import brings over everything it lists. On Linux the wizard cannot read those browsers' passwords: export them to a CSV file there and import it in about:logins.

Imported bookmarks land in Firefox's own folders, and the bookmarks panel shows only the current workspace's folder: set root = "toolbar" (or "all") under [bookmarks] in config.toml to see them. Every step, and what does not come over, is in Moving over from Firefox or Chrome under Details.

On macOS, Option types characters, so the keys that are alt chords on Linux are Firefox's Mac keys there: cmd+left / cmd+right and cmd+[ / cmd+] for back and forward, cmd+1…cmd+9 for the tabs and cmd+l for the address bar. Firefox's other cmd keys, such as cmd+t and cmd+w, are off unless you list them in enable; cmd+q still quits. See On macOS the alt keys are cmd keys.

Firefox's keys are Vimma bindings

Most of Firefox's keys, such as ctrl+t, alt+left (cmd+left on macOS), F5, ctrl+plus and F12, are Vimma's own bindings with Firefox's meaning. ctrl+b ? lists them under their actions, and [keys] in config.toml rebinds them by name, as any other key: new_tab = ["prefix+c"] takes ctrl+t away from "New tab". A page that uses one of them itself, such as an editor that saves on ctrl+s, still gets it first, as in Firefox.

Vim's keys in text fields

While you type, in a page's field, the URL bar, the : line or a filter, ctrl+w deletes the word before the caret, ctrl+u the rest of the line before it, and ctrl+h one character. ctrl+z undoes them. A page with its own use for the key, such as a web terminal, keeps it. Turn them off with insert_editing = false under [modal].

Choose your own

The list is yours in config.toml. Give a shortcut back to Firefox, or switch off every Firefox shortcut except a few:

[firefox]
enable = ["ctrl+w"]        # ctrl+w closes the tab again, even in a text field

# or: only ctrl+t, ctrl+l (and ctrl+q) stay Firefox's
# disable = "all"
# enable = ["ctrl+t", "ctrl+l"]

about:vimma lists every Firefox shortcut that is off right now.

Your add-ons

Add-ons work as in Firefox, and now they answer to the keyboard too: open your password manager's vault, an add-on's options or its updates without reaching for the toolbar. Install them from addons.mozilla.org, the add-on's page and its Add button, as in Firefox; Vimma never installs anything by itself.

  1. Press ctrl+b e (or type :addons). Every add-on you installed is listed, with its version and whether it is on.
  2. Move with j and k, or press / and type a few letters of its name.
  3. Press Enter: its popup opens with keyboard focus inside, so you can type at once. Esc closes it.

In the list, o opens its options, x turns it on or off, d removes it (after asking), u checks for an update and P allows it in private windows or not. :addon bw opens Bitwarden's popup from a few letters of its name, and Tab completes the name.

You will not need Vimium, Tridactyl or Surfingkeys: hints, scrolling, find and the command line are built in, and a second set of bindings would compete for the same keys. Container add-ons work, but workspaces are containers already, and a tab such an add-on opens in a container of its own belongs to no workspace.

What else Vimma changes

A few Firefox defaults change for workspaces, and each can be changed back in about:config:

  • A restart restores your tabs, workspaces, pane layouts and scroll positions.
  • Closing the last tab keeps the window and opens a new tab.
  • A download opens no downloads panel: the status bar shows it and ctrl+b d lists it.
  • Help links open vimma.dev, which forwards any topic Vimma does not document to Mozilla's article.

Settings hides what does nothing in Vimma, such as Firefox themes, the tab layout and the data collection switches, and menus drop Mozilla's promotions. The full list, with each preference, is in Firefox behaviour Vimma changes under Details. What Vimma turns off for privacy is on Privacy defaults.
