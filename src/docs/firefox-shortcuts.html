A key in Vimma means one thing. Where Firefox had a shortcut on a key Vim uses, such as ctrl+w or ctrl+d, Vimma switches Firefox's off, so you never close a tab when you meant to delete a word.

What moved where

Firefox's keyIs nowFirefox's action is on
ctrl+w close tabPane keys; delete a word in a text fieldx, ctrl+b shift+x, :q
ctrl+u page sourceHalf a page up; delete to the line's start when typinggf
ctrl+d bookmarkHalf a page downctrl+b a
ctrl+o open file, ctrl+i page infoBack / forward, as Vim's jump list:open file:///path; the context menu's page info
ctrl+h historyBackspace when typingctrl+shift+h
ctrl+k web searchFree for youI, then type the search
ctrl+b bookmarks sidebarVimma's prefixctrl+b shift+b

Everything else works as in Firefox: ctrl+t, ctrl+shift+t, ctrl+l, ctrl+f, ctrl+tab, alt+1…alt+9, ctrl+q and the rest.

Firefox's keys are Vimma bindings

Most of Firefox's keys, such as ctrl+t, alt+left, F5, ctrl+plus and F12, are Vimma's own bindings with Firefox's meaning. ctrl+b ? lists them under their actions, and [keys] in config.toml rebinds them by name, as any other key: new_tab = ["prefix+c"] takes ctrl+t away from "New tab". A page that uses one of them itself, such as an editor that saves on ctrl+s, still gets it first, as in Firefox.

Vim's keys in text fields

While you type, in a page's field, the URL bar, the : line or a filter, ctrl+w deletes the word before the caret, ctrl+u the rest of the line before it, and ctrl+h one character. ctrl+z undoes them. A page with its own use for the key, such as a web terminal, keeps it. Turn them off with insert_editing = false under [modal].

Choose your own

The list is yours in config.toml. Give a shortcut back to Firefox, or switch off every Firefox shortcut except a few:

[firefox]
enable = ["ctrl+w"]        # ctrl+w closes the tab again, even in a text field

# or: only ctrl+t, ctrl+l (and ctrl+q) stay Firefox's
# disable = "all"
# enable = ["ctrl+t", "ctrl+l"]

about:vimma lists every Firefox shortcut that is off right now.
