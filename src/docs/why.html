Extensions get as far as the page. Vimma starts where they stop.

Vimium and Tridactyl bring Vim keys to the page, and they do it well; Vimma builds on their ideas. An extension, though, works within the limits of the extension API, and some things sit outside those limits by design.

A browser, not an extension

  • Your keys work on the browser's own pages too. Extensions do not run on the browser's own pages, such as about: pages, the new tab page and the add-ons store, so a Vim extension's keys stop there. Vimma's keymap is part of the browser, so j, f and ctrl+b work on those pages too (all but extension, data: and blob: pages).
  • Sites cannot take your keys. Gmail, GitHub and Google Docs claim keys for themselves, and an extension has to compete with them for each one. Vimma sees every key before the page does and decides who gets it, so f shows link hints even on GitHub. When you type in a text field, insert mode passes every key to the page except ctrl+b, Esc and Firefox's reserved keys.
  • One keymap for the whole browser. A tab strip from one extension, containers from another and a Vim layer from a third give you three keymaps that know nothing of each other, on top of Firefox's own shortcuts. Vimma has one keymap: tabs, split panes, workspaces, bookmarks and the URL bar all answer to ctrl+b and Vim motions, and none of Firefox's default shortcuts collides with it.
  • Things an extension is not meant to do. Tiling panes with tmux layouts, and a status bar that always shows the mode, change the browser window itself, which is outside what the extension API offers.
  • One file for every key. Your whole keymap lives in a single config.toml that reloads when you save. Rebind any key, including the prefix. On Omarchy, Vimma also follows your desktop theme live.
  • Less third-party code with access to every page. A Vim extension needs permission to read and change every site you visit. In Vimma that code is part of the browser itself: open source, tested, and scanned on every change.

Firefox is still underneath, with the same engine, add-ons and protections, and Vimma is rebased onto each Firefox security release and tested automatically within hours.

Who gets a key, Vimma or the page, is under Modes and moving.

Which one?

  • You want Vim keys in the browser you already use, on any desktop system: Vimium, or Tridactyl in Firefox.
  • You want a mature keyboard browser and can do without Firefox's add-ons: qutebrowser.
  • You want a polished Firefox with workspaces and split view, on Linux, macOS or Windows: Zen.
  • You live in the terminal on Linux or a Mac, want your Vim and tmux habits across the whole browser, want to keep Firefox's add-ons, and accept pre-alpha software: Vimma. Next: install it.
