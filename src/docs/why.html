Extensions get as far as the page. Vimma starts where they stop.

Vimium and Tridactyl bring Vim keys to the page, and they do it well; Vimma builds on their ideas. But an extension is a guest in the browser: Firefox decides where it may run and what it may touch.

  • Your keys work where extensions cannot. Firefox does not run extensions on its own pages: the add-ons store, about: pages and the new tab page. A Vim extension therefore goes silent on exactly the pages you most want to leave quickly. Vimma's keymap is part of the browser, so j, f and ctrl+b work on those pages too.
  • Sites cannot take your keys. Gmail, GitHub and Google Docs claim keys for themselves, and an extension has to compete with them for each one. Vimma sees every key before the page does and decides who gets it, so f shows link hints even on GitHub. When you type in a text field, insert mode passes everything through except ctrl+b and Esc.
  • One keymap for the whole browser. A tab strip from one extension, containers from another and a Vim layer from a third give you three keymaps that know nothing of each other, on top of Firefox's own shortcuts. Vimma has one keymap: tabs, split panes, workspaces, bookmarks and the URL bar all answer to ctrl+b and Vim motions, and none of Firefox's default shortcuts collides with it.
  • Things no extension can do. Tiling panes with tmux layouts, and a status bar that always shows the mode, change the browser window itself, which the extension API does not allow.
  • One file for every key. Your whole keymap lives in a single config.toml that reloads when you save. Rebind any key, including the prefix. On Omarchy, Vimma also follows your desktop theme live.
  • Less third-party code with access to every page. A Vim extension needs permission to read and change every site you visit. In Vimma that code is part of the browser itself: open source, tested, and scanned on every change.

Firefox is still underneath, with the same engine and add-ons, and Vimma is rebased onto each Firefox security release and tested automatically within hours.
