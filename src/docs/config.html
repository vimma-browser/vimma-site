~/.config/vimma/config.toml. Created on a profile's first run with every default commented out. Save, and it applies within 2 s. :config opens it.

Edit the file

  • Uncomment a line, change its value, save.
  • Every window picks it up within 2 s, with no restart. :source reloads it at once.
  • :source work.toml loads another file instead, until config.toml changes.
  • No file means the defaults. Vimma never rewrites a file you have; :route add only appends.

Remap a key

Every key, the ctrl+b prefix and the space leader can be remapped. Use the action names in the Name column of the keys page; a new binding replaces the default.

[keys]
prefix = "ctrl+a"        # ctrl+b by default, as in tmux
new_tab = ["prefix+t"]   # instead of prefix c and ctrl+t
# the side panel: prefix b, and now also leader n
toggle_sidebar = ["prefix+b", "<leader>n"]

[modal]
leader = ","             # space by default; no keys of its own

Firefox's own keys, such as ctrl+t and F5, are remapped the same way (Firefox's keys are Vimma bindings).

Other things you can set

Each block shows the defaults as key = default # what it takes. A line starting with # has no default: remove the # to use it.

If you make a mistake

  • A file with an error is not applied; your last working setup keeps working.
  • The status bar shows the first error in red, with its line: config.toml:3: keys.new_tabb: unknown action "new_tabb" (did you mean "new_tab"?)
  • Fix the line and save. about:vimma lists every error.

about:vimma

  • about:vimma (or :about): version, updates, your config and its errors, the theme, workspaces, and the last keys Vimma saw. r refreshes it.
  • :bug copies it as a report with URLs and your home directory redacted. Read it before you post it.

about:config

A few switches live in about:config, with these defaults:

vimma.ui.tabstrip.hidden = true      # false: Firefox's tab strip again
vimma.ui.toolbar.hidden = true       # Firefox's toolbar; ctrl+b u sets it
vimma.ui.pdf_outline.hidden = false  # true: PDFs open without the outline
vimma.startpage.newtab = true        # false: Firefox's new tab page
vimma.update.enabled = true          # false: no update checks
vimma.control.enabled = false        # true: the socket for vimma-ctl
vimma.theme.source = "omarchy"       # "builtin": Vimma's palette
vimma.theme.appearance = "system"    # what :theme sets
vimma.theme.omarchyHook = true       # false: removes Vimma's theme hook
vimma.config.pollMs = 2000           # how often config.toml is checked
# vimma.config.path = "…"            # another file instead of config.toml
# vimma.debug.keys = true            # log keys to the Browser Console

Colours and Omarchy

One theme colours Vimma's bars, pickers and hints, and Firefox's toolbar, menus, dialogs and Settings pages.

SourceWhat you get
OmarchyYour current Omarchy theme, followed live. The default where Omarchy is installed.
Built inVimma's palette, dark or light like your system. The default elsewhere.
config.tomlSingle colours of your own, over either one.

Dark or light

  • :theme dark or :theme light: the built-in palette stays that way.
  • :theme system: follow the system again (the default).
  • :theme: switch to the other one. Vimma remembers the choice across restarts.
  • On Omarchy, your Omarchy theme decides.

Your own colours

[theme]
source = "file"      # on Omarchy: the built-in palette instead
appearance = "dark"  # or "light", "system"; wins over :theme
[theme.colors]
accent = "#ff9e64"   # any key of Omarchy's colors.toml

With Omarchy

  • Nothing to set up: omarchy-theme-set or the Omarchy menu recolours every window, with no restart.
  • Vimma installs a hook in ~/.config/omarchy/hooks/theme-set.d/ so it changes with your desktop. Edit or delete it, and Vimma leaves it that way.
  • Without the hook, Vimma still follows within 2 s.
