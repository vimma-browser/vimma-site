Vimma uses Firefox's own bookmarks, the ones you imported, synced or see in the Library, and gives them keys: one to file a page, one to open a panel where you find it again.

Bookmark a page

  1. Press ctrl+b a. A prompt opens at the bottom of the window with the page's title in it.
  2. To file it in folders, type them in front of the title, separated by /: work/docs/My page. Missing folders are made; Tab completes a folder name.
  3. Press Enter to save, or Esc to cancel.

A page that is already bookmarked shows where it is; edit the path to move or rename it. Paths start in the Bookmarks Menu; begin with toolbar/ or other/ for the other two top folders.

Find a bookmark

ctrl+b shift+b opens your bookmarks as a tree on the left of the window. The quickest way in is /: type a few letters of a title, address or folder.
