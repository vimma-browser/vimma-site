Once an agent is connected to the agent workspace, it can work on a page there much as you do with hints: move around it, list its buttons and fields, click them, fill in forms, and see the page and its errors. Each tool asks you first, and everything happens in the background, so your window keeps its workspace, tab and focus.

ToThe agent uses
Scroll, find a word, follow a link, go back or forwardvimma_keys
List the buttons, fields and links on screen, each with a hint labelvimma_elements
Click one of themvimma_activate
Fill in fields, and send the form if you agreevimma_fill
See the page as you wouldvimma_screenshot
Read the page's script errors and failed requestsvimma_console
Show you one of its tabsvimma_show

What always asks

Sending a form asks every time, also while you have allowed a tool for some minutes, and the question says where the data goes. Password, payment card and one-time-code fields are never filled: the agent asks you to type them.
