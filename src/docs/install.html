Install Vimma on Linux x86_64 from its package repositories or a release, or on a Mac with Apple Silicon and macOS 15 or later, or build it from source, then start it with a profile of its own, so your Firefox profile is never touched.

Install it

On Linux, add Vimma's signed package repository once, and updates come with your system upgrade. On Arch Linux, import and trust the key, whose fingerprint is 1106 49CB 2BC1 1400 828D D0D4 97FD 3D2B 24AD 4390:

curl -fsSL https://updates.vimma.dev/vimma-packages.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key 110649CB2BC11400828DD0D497FD3D2B24AD4390

add the repository to the end of /etc/pacman.conf, then run sudo pacman -Syu vimma-bin:

[vimma]
Server = https://updates.vimma.dev/arch/$arch

On Debian and Ubuntu, the setup is one file that holds the same key, then sudo apt update && sudo apt install vimma:

curl -fsSL https://updates.vimma.dev/apt/vimma.sources | sudo tee /etc/apt/sources.list.d/vimma.sources

On Fedora, sudo dnf config-manager addrepo --from-repofile=https://updates.vimma.dev/rpm/vimma.repo, then sudo dnf install vimma; on openSUSE, sudo zypper addrepo --refresh --gpgcheck-strict https://updates.vimma.dev/rpm/vimma.repo, then sudo zypper refresh && sudo zypper install vimma. dnf and zypper show the key's fingerprint, the one above, and ask once before they trust it. The install page has each step.

Without a repository, the latest release has an AppImage and a tarball, which update themselves, and a .deb and an .rpm. Vimma tells you in the status bar when a newer release is out, and :update shows the command to install it. Installing, below, explains how to verify a download.

On a Mac with Apple Silicon and macOS 15 (Sequoia) or later, install it with Homebrew, or open the release's .dmg and drag Vimma into Applications:

brew install --cask vimma-browser/tap/vimma

Vimma is signed with its Apple Developer ID and notarised by Apple, so it opens like any other app. It tells you of a newer release as on Linux, and brew upgrade --cask vimma updates it. The install page has the details.

The vimma-bin package puts vimma on your PATH; it, the .deb and the .rpm add Vimma to your application menu. Vimma's profiles live in ~/.config/vimma/vimma/, separate from Firefox's.

Or build it

The commands, requirements and timings are on the install page. In short: Linux x86_64, about 35 GB of free disk, Node.js 22.18 or later in the 22 line or 24.3 or later, Python 3.10 to 3.14, git and gpgv, and about 40 minutes for the first build.

Start a source build

From the checkout:

npm start                   # your build, with its own profile
npm start -- --fresh        # a throwaway profile, deleted when Vimma quits
npm start -- --profile DIR  # another profile you keep

The profile lives in ~/.cache/vimma-dev-profile. Vimma will not open the same profile twice: if it refuses to start, switch to the window that is already open.

Where Vimma keeps its files

PathWhat
~/.config/vimma/config.tomlYour settings and key bindings (see config.toml). Vimma writes it on the first launch, every line commented out, so you have the whole format to start from.
~/.config/vimma/vimma/Installed Vimma's profiles on Linux; on a Mac, ~/Library/Application Support/Vimma/. A build started with npm start uses ~/.cache/vimma-dev-profile instead.
