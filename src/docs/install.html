Install Vimma from a release on Linux x86_64 or on a Mac with Apple Silicon, or build it from source, then start it with a profile of its own, so your Firefox profile is never touched.

Install it

On Arch Linux, run this as your normal user, from any directory. The same command installs and updates, and ~/.cache/vimma-build, where it builds, can be deleted at any time:

{{arch_install}}

On other distributions, the latest release has a .deb, an .rpm, an AppImage and a tarball. Vimma tells you in the status bar when a newer release is out, and :update shows the command to install it; only the AppImage and the tarball update themselves. The install page has the details, and Installing, below, explains how to verify a download.

On a Mac with Apple Silicon, install it with Homebrew, or open the release's .dmg and drag Vimma into Applications:

brew install --cask vimma-browser/tap/vimma

Vimma is signed with its Apple Developer ID and notarised by Apple, so it opens like any other app. It tells you of a newer release as on Linux, and brew upgrade --cask vimma updates it. The install page has the details.

The Arch package puts vimma on your PATH; it, the .deb and the .rpm add Vimma to your application menu. Vimma's profiles live in ~/.config/vimma/vimma/, separate from Firefox's.

Or build it

The commands, requirements and timings are on the install page. In short: Linux x86_64, about 35 GB of free disk, Node.js, Python 3 and git, and about 40 minutes for the first build.

Start a source build

From the checkout:

npm start                   # your build, with its own profile
npm start -- --fresh        # a throwaway profile, deleted when Vimma quits
npm start -- --profile DIR  # another profile you keep

The profile lives in ~/.cache/vimma-dev-profile. Vimma will not open the same profile twice: if it refuses to start, switch to the window that is already open.

Where Vimma keeps its files

PathWhat
~/.config/vimma/config.tomlYour settings and key bindings (see config.toml). Vimma writes it on the first launch, every line commented out, so you have the whole format to start from.
~/.config/vimma/vimma/Installed Vimma's profiles on Linux; on a Mac, ~/Library/Application Support/Vimma/. A build started with npm start uses ~/.cache/vimma-dev-profile instead.
