The private workspace is Firefox's private browsing, reached like any other workspace. Because it is a real Firefox private window, the history, cookies, site storage, cache, form history and download records it collects are discarded when you close it.

Use it

  1. Press ctrl+b shift+p (or ctrl+shift+p, or :private). The private workspace opens, and the status bar says ◆ private.
  2. Browse as usual: hints, find, splits, copy mode and the side panel work as in any workspace.
  3. Press ctrl+b shift+p again, or ctrl+^, to go back to where you were. The private workspace stays open, one key away.
  4. When you are done, ctrl+b shift+d in it (or :private close anywhere) asks for confirmation (y/N), then closes it and discards its data.

Good to know

  • Reached by its own key only. ctrl+b ( / ), ]w / [w and ctrl+^ never land in it by accident; from inside it, they take you out.
  • There is only one. Every private window belongs to it, and they all share one cookie jar, as Firefox's private windows do.
  • The workspace picker (ctrl+b w) lists it last, with a tab count only, never a title or an address. m on that row reopens the current tab there; a private tab never moves out.
  • On Hyprland it takes your Vimma window's place, in the same tile and size, and your normal window comes back when you switch. Elsewhere it is a second window.
  • Add-ons run there only if you allowed them in private windows (ctrl+b e, then P).
  • Not hidden: the clipboard. What you copy there stays there after the workspace closes. The window's title, on the other hand, is always Vimma Private Browsing, never the page's.
