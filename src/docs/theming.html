Vimma's own parts of the window, the status bar, the command line, the pickers, link hints, pane borders and the start page, share one colour theme. Out of the box it is Tokyo Night, the palette of this site.

Where the colours come from

SourceWhat you get
Omarchy, if you use itYour current Omarchy theme, followed live. This is the default whenever Omarchy is installed.
Built inTokyo Night. The default without Omarchy.
Your config.tomlSingle colours of your choice, on top of either one.

Your own colours

Set colours under [theme.colors] in config.toml. Save, and every window recolours within two seconds:

[theme]
source = "file"     # the built-in Tokyo Night; leave this out to follow Omarchy
[theme.colors]
accent = "#ff9e64"

To use Tokyo Night on Omarchy without a config file, set vimma.theme.source to builtin in about:config.

With Omarchy

There is nothing to set up. Switch themes with omarchy-theme-set or the Omarchy menu, and every Vimma window follows, without a restart.

So that it changes at the same moment as the rest of your desktop, Vimma puts a small hook, vimma-theme-reload.sh, in ~/.config/omarchy/hooks/theme-set.d/ the first time it starts. Edit it and Vimma leaves it alone; delete it and it does not come back. Without the hook, Vimma still notices a new theme within two seconds.
