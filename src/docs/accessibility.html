Vimma's own parts, from the status bar and the ctrl+b ? overlay to the pickers, panels and command line, work with a screen reader on top of Firefox's own support. On Linux that is Orca.

  • Each overlay, picker, panel and prompt takes focus when it opens and gives it back when it closes.
  • The status bar is a status bar to your screen reader; it never announces titles or URLs as they change.
  • All text Vimma draws reaches WCAG AA contrast in the built-in themes, and nothing in its UI animates.
  • Every key can be remapped, including one-key bindings that avoid chords: see config.toml.
