Vimma keeps Firefox's protections and turns off the parts that are not about browsing: studies, sponsored content and promotions. Every default is a preference you can change back in about:config.

Turned off

  • Studies and experiments (Normandy and Nimbus).
  • Sponsored stories, shortcuts and URL bar suggestions.
  • Feature and add-on recommendations, and Mozilla's promos (VPN, Relay, mobile).
  • Page titles in a private window's title bar: the window manager, its bar and screen sharing see only Vimma Private Browsing.
  • Telemetry upload and the crash reporter: neither is built in, so Vimma sends nothing. A crash leaves whatever record your system keeps: a core dump where systemd-coredump keeps them (coredumpctl list | grep vimma, which also finds a tab's process), a .ips report on macOS.

Kept as in Firefox

  • Safe Browsing: Vimma downloads Google's lists of dangerous sites and warns you before you open one. Your browsing stays local; only when an address matches the list does Vimma send Google a short hash of it to confirm.
  • Certificate revocation checks, the add-on blocklist, Firefox Sync and add-ons from addons.mozilla.org.

Still contacts Mozilla

Very little. Firefox's updater, which the tarball uses to update itself, asks Vimma's own server, updates.vimma.dev, and system add-on updates are off, so Vimma never asks Mozilla's update server for a Firefox build. Vimma's update check fetches a small file from the same server and refuses it unless it is signed with a key built into Vimma. The one request left there is for the OpenH264 and Widevine plugins, which video calls and DRM video need.

Sites see Firefox

Vimma sends Firefox's user agent, byte for byte, and add-ons see Firefox's version, so nothing treats it as a different browser.

Change any of it back

Open about:config, search for the preference and toggle it. The table under Details names the preference for each default.
