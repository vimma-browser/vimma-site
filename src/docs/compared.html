Each of these is good at something. Here is what each does well, and where Vimma is different.

Vimma owes a lot to every project on this page. If one of them already fits the way you work, keep it. The table sets them side by side; the sections under it say more.

Vimium

Good at: being simple and everywhere. It is mature, its link hints and Vomnibar take minutes to learn, and it runs in Chrome, Edge and Firefox, so the same keys follow you from browser to browser. Vimium C, a fork, adds much more for those who want it.

Where Vimma differs: Vimium is a guest in the browser, so it stops where extensions stop: on the browser's own pages, the extension store and the PDF viewer. Tabs, windows and anything beyond the page are the browser's. Vimma's keys are part of the browser, and the ctrl+b layer adds panes and workspaces. Vimium needs no new browser; Vimma does.

Tridactyl

Good at: depth. It is the closest heir to Vimperator and Pentadactyl: almost everything is an ex command you can bind, chain or put in your tridactylrc, and with its native messenger you can edit any text field in your own Vim.

Where Vimma differs: Firefox does not load Tridactyl on about: pages, view-source: and data: pages or addons.mozilla.org. Vimma's keys work on about: pages and addons.mozilla.org too, and Vimma sees each key before the page does. Tridactyl has far more commands today, and works in any Firefox; Vimma is a separate, pre-alpha browser.

qutebrowser

Good at: being a whole keyboard browser, for a long time. It has a minimal interface, keys that work everywhere, configuration and user scripts in Python, and builds for Linux, macOS and Windows.

Where Vimma differs: qutebrowser is built on Qt WebEngine, which is Chromium, and does not run WebExtensions, so add-ons such as uBlock Origin or a password manager's do not run in it (it has its own ad blocker and Greasemonkey user scripts). Vimma is Firefox underneath, with Firefox's add-ons, containers and privacy settings. Vimma also tiles panes inside one window and groups tabs into workspaces, as tmux does; qutebrowser keeps to tabs and windows.

Zen Browser

Good at: making Firefox calm and beautiful. Vertical tabs, workspaces with their own containers and colours, split view, compact mode and a large community of mods, with release builds for Linux, macOS and Windows. Vimma is built with Surfer, the toolchain Zen made, and is grateful for it.

Where Vimma differs: Zen's interface is made for the mouse and trackpad as well as shortcuts, and it has no modal layer: for Vim keys you add an extension, with an extension's limits. Vimma is keyboard-first: one keymap for pages, tabs, panes and workspaces, Vim modes on every page and a status bar that shows the mode. Zen is released and cross-platform; Vimma is pre-alpha and Linux only.

Also worth a look

  • Nyxt is a browser written and configured in Common Lisp, programmable while it runs, with Emacs, vi and CUA key schemes. Its 4.0 release renders with Electron (Chromium); it is supported on Linux, with macOS in development.
  • Vieb is an Electron (Chromium) browser with the most literal Vim feel of all: modes down to a keyboard pointer, Vim-style splits with ctrl+w, and a viebrc. It runs on Linux, macOS and Windows, has a built-in ad blocker, and does not support extensions.

Which one?

  • You want Vim keys in the browser you already use, on any system: Vimium, or Tridactyl in Firefox.
  • You want a mature keyboard browser and can do without Firefox's add-ons: qutebrowser.
  • You want a polished Firefox with workspaces and split view, on any system: Zen.
  • You live in Vim and tmux on Linux, want those habits for the whole browser and keep Firefox's add-ons, and don't mind building a pre-alpha from source: Vimma. Start with why a browser and not an extension, then install.
