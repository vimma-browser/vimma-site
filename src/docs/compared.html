Vimma side by side with the keyboard browsers and extensions people already use, and a short guide to choosing.

Vimma owes a lot to every project on this page. If one of them already fits the way you work, keep it. Vimma is built with Surfer, the Firefox build toolchain Zen maintains, and is grateful for it.

Who gets a key. In normal mode a page never sees Vimma's bare keys (j, f, /); keys Vimma does not bind still reach it. Firefox's shortcuts that a page may use, such as ctrl+s in an editor, and Esc go to the page first, as in Firefox, unless the site's Override keyboard shortcuts permission is Block. Reserved keys such as ctrl+t and ctrl+w stay the browser's.

Which one?

  • You want Vim keys in the browser you already use, on any desktop system: Vimium, or Tridactyl in Firefox.
  • You want a mature keyboard browser and can do without Firefox's add-ons: qutebrowser.
  • You want a polished Firefox with workspaces and split view, on Linux, macOS or Windows: Zen.
  • You live in the terminal on Linux or a Mac, want your Vim and tmux habits across the whole browser, want to keep Firefox's add-ons, and accept pre-alpha software: Vimma. Start with why a browser and not an extension, then install.
