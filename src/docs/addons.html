Add-ons work as in Firefox: install them from addons.mozilla.org as usual. Vimma adds keyboard control, so you can open a password manager or an ad blocker's panel without reaching for its toolbar button.

The add-on picker

ctrl+b e (or :addons) lists the add-ons you installed, each with its version and whether it is on.

Open one add-on by name

:addon bw opens the popup of the add-on whose name matches, Bitwarden here; Tab completes the name. Inside a popup the keys are the popup's, so you can type in its search box at once; Esc closes it.
