Help

Vimma's help links open here: Help > Get Help, the support button in Settings, and the "Learn more" links beside Firefox's settings. Most answers about the keys, panes and workspaces are in the docs.

  • FAQ and troubleshooting, below: profiles, updates, the tab strip, ctrl+b and crash reports.
  • Known limits: what does not work yet.

First checks

  • Keys type instead of doing something? A text field has focus (the badge says INSERT). Press Esc.
  • Not sure what a key does? ctrl+b ? lists them all; / filters.
  • Your config.toml change did nothing? Look at the right of the status bar for a red error, or open about:vimma.

Everything else is Firefox

Vimma is built on Firefox {{firefox_major}} and keeps most of it as Firefox has it: Sync, passwords, certificates, tracking protection, and add-ons from addons.mozilla.org. A help link about one of these opens the matching article in Mozilla's Firefox help, which describes Vimma too. Where an article names a Firefox shortcut, Firefox's shortcuts says where Vimma puts it.

Report a bug

In Vimma, type :bug. It opens about:vimma and copies its redacted report to the clipboard: the version, the Firefox release under it and the build, how Vimma was installed, your config.toml's errors and the keys it changes, the last keys Vimma saw, and the state of the workspaces, the theme and the agent tools. Every URL in it (anything with ://) is replaced by <url> and your home directory by ~, and it holds no page titles. Keys typed into a text field or on the command line show as ·. Your workspace names and the text of any config errors stay in it, so read it before you paste it.

Then search the open issues; if one matches, add to it. If none does, open a bug report and include:

  • the version: the report has it, or run vimma --version;
  • how you installed Vimma: the Arch Linux command, a .deb or .rpm, the AppImage, the tarball, Homebrew or the .dmg, or a build from source;
  • your system: the Linux distribution and desktop, or the macOS version;
  • what happened, with any message in the status bar or the Browser Console, the steps that show it, from a fresh start where you can, with the keys you pressed, and what you expected instead.

A security problem is reported privately, never in a public issue: use Report a vulnerability on the repository's Security tab, as the security policy describes.

What a help link sends

A help link carries the Firefox version, your operating system and your language in its address, as Firefox's own help links do. This site sets no cookies and has no analytics.
