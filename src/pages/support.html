Help

Vimma's help links open here: Help > Get Help, the support button in Settings, and the "Learn more" links beside Firefox's settings. Most answers about the keys, panes and workspaces are in the docs.

Everything else is Firefox

Vimma is built on Firefox {{firefox_major}} and keeps most of it as Firefox has it: Sync, passwords, certificates, tracking protection, and add-ons from addons.mozilla.org. A help link about one of these opens the matching article in Mozilla's Firefox help, which describes Vimma too. Where an article names a Firefox shortcut, Firefox's shortcuts says where Vimma puts it.

Ask or report

  • Questions and ideas: GitHub Discussions.
  • Bugs: GitHub issues, with the version from vimma --version or about:vimma.
  • Security problems: privately, as the security policy describes, not in a public issue.

What a help link sends

A help link carries the Firefox version, your operating system and your language in its address, as Firefox's own help links do. This site sets no cookies and has no analytics.
