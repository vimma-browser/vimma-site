vimma a keyboard-first browser, built on Firefox

Vim modes on every page and tmux-style workspaces and splits behind ctrl+b, so your hands stay on the keys; Firefox underneath keeps your sites and add-ons working.

install

Vimma 0.1.1 is out for Linux x86_64. On Arch Linux, run this as your normal user in an empty directory:

$ curl -fLO https://github.com/vimma-browser/vimma/releases/latest/download/PKGBUILD && makepkg -si

Run it again in the same directory to update: the in-app updater is not active yet. Other distributions: a .deb, an AppImage and a tarball in the latest release, with checksums and signatures (how to check them). More on the install page.

what it does

j k / :
Scroll, find and run commands from the home row; in a field you type as usual, and Esc brings you back.
f F
A label on every link, button and field, in frames too.
ctrl+b w
Workspaces: containers with their own logins, tabs, split and bookmarks, kept across restarts.
ctrl+^
Back to the last workspace, as Vim's alternate buffer.
ctrl+b v
Split panes, in tmux's layouts, tiled and spiral included.
ctrl+b shift+p
A private workspace: nothing kept on disk.
ctrl+b b
The workspace's tabs in a side panel, when you ask.
ctrl+b a
Firefox's bookmarks, a folder per workspace.
ctrl+b e
Add-ons on a key: open, toggle, update or remove them.
status bar
Mode, keys, workspace, tab 2/5, title, URL, find matches.
config.toml
Remap any key and the prefix; applies on save. How.
[theme]
Mint and near-black, dark or light, or your Omarchy theme, live. How.
:mcp on
Local AI agents through MCP, confined to an agent workspace; each request asks you first. How.
about:config
No telemetry upload, studies, crash reporter or sponsored content.
Firefox 158
The release channel: sites and add-ons see Firefox.

Every key is on the keys page; the docs walk through them in order.

a minute in vimma

why not an extension

Extensions live inside the page; Vimma lives in the browser. So the keys work where extensions can't, nothing steals them, and tabs, panes and workspaces answer to the same keymap. Why Vimma.

the name

Vimma is Finnish for a burst of eager, focused energy. You hear it in työvimma: a spell of work where everything flows and the hours slip by. It also happens to start with Vim.
