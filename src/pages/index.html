Vimma: A browser for people who live in the terminal

Vim modes on every page, tmux-style workspaces and splits.

Single keys drive the page, and a prefix key, as in tmux, drives tabs, panes and workspaces, so your hands never leave the keyboard. Firefox is underneath, so your sites and add-ons keep working.

What it does

  • reading

    Modal pages

    Read, scroll, search and run commands from the home row. In a text field, keys type as usual.

  • navigation

    Link hints

    Every link, button and field on screen gets a short label, including in embedded frames. Type the label to follow it.

  • isolation

    Workspaces

    Each workspace is a Firefox container with its own logins, tabs, split and bookmarks folder, restored after a restart.

  • layout

    Split panes

    Pages side by side, with tmux's layouts: move between panes, zoom, swap and resize them from the keyboard.

  • configuration

    Every key is yours

    Remap any binding, and the prefix itself, in one config.toml. Changes apply when you save. How.

  • automation

    Local AI agents

    Agents such as Claude Code and Codex can browse through MCP, confined to a workspace of their own. Vimma asks you before it acts on each request. How.
