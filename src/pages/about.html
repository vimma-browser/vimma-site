About

Vimma is a keyboard-first browser for people who live in Vim and tmux, so that browsing keeps the flow of the rest of your work. Vim brings the modal layer: j k scroll, f shows link hints, / finds, : runs commands. tmux brings the prefix: after ctrl+b, c opens a tab, v splits and w switches workspace. Every key, and the prefix, can be remapped in config.toml.

Why another browser, and not an extension?

Extensions such as Tridactyl and Vimium come close, but an extension cannot reach every key. Vimma's dispatcher sees each key before Firefox does, including in the URL bar, on about: pages and in the PDF viewer.

Splits, workspaces and a status bar belong to the window, and no extension owns the window. In Vimma they are built in. The long version: Why Vimma.

What does the name mean?

Vimma is Finnish for a burst of eager, focused energy. You hear it in työvimma: a spell of work where everything flows and the hours slip by. It also happens to start with Vim.

What are the privacy defaults?

Off by default: Mozilla's studies and rollouts (Normandy, Nimbus), sponsored new-tab content and suggestions, feature recommendations and Mozilla promos. The build has no crash reporter and no telemetry upload, so nothing is sent to Mozilla; a crash leaves only a local core dump.

Kept as in Firefox: certificate revocation (CRLite), the add-on blocklist, Sync and add-ons from addons.mozilla.org. Google Safe Browsing is on in builds made with a Google API key. Each default can be changed in about:config.

Firefox's own updater is not built in, and system add-on updates are off, so Vimma never asks Mozilla's update server for a Firefox build. The one request it still makes there is for the OpenH264 and Widevine plugins, which video calls and DRM video need.

What is underneath?

Firefox {{firefox_major}}, on the release channel, so you get Mozilla's engine and its add-on ecosystem. Vimma is built with Surfer, the toolchain behind Zen Browser. Vimma's code lives in its own files, with small patches to Firefox. Sites see Firefox's user agent byte for byte, and add-ons see Firefox's version number, so the web treats Vimma as Firefox.

How private are workspaces?

Each workspace is a Firefox container: cookies, logins, site storage and site permissions are separate. History and form history are shared by all workspaces, as they are between Firefox containers, and so are bookmarks, with a folder for each workspace. For browsing that leaves nothing on disk, use the private workspace, Firefox's private browsing one key away.

Can AI agents use Vimma?

Only if you let them. Turn agents on with :mcp on, and a local agent such as Claude Code or Codex can open, read and close tabs through vimma-ctl mcp, in the agent workspace only, with its own logins. Vimma asks you before it acts on each request. See The agent workspace.

Do I need Omarchy?

No. On Omarchy, Vimma follows your theme and recolours when you change it. Elsewhere it uses its built-in palette, the mint and near-black of this site, in a dark or light variant to match your system. You can also set your own colours in config.toml.

Which platforms?

Linux x86_64 is the only platform built and tested today; macOS is next. See install.

What is the licence?

MPL-2.0, like Firefox. This website is MPL-2.0 too, its text and the logo included.

Where is the source?

On GitHub, at github.com/vimma-browser/vimma, public since 10 October 2026. The releases for Linux x86_64, the issue tracker and the specification behind each feature are there too.

Does this site track me?

No. It sets no cookies, runs no analytics and loads no fonts, scripts or images from other servers. The site's own keys (press ?) store one setting in your browser's local storage: whether they are on.
