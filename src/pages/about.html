About

Vimma is a keyboard-first browser built on Firefox, for people who live in the terminal: Vim's modes on every page, and tmux's ctrl+b prefix for tabs, panes and workspaces. Every key, and the prefix, can be remapped in config.toml.

What does the name mean?

Vimma is Finnish for a burst of eager, focused energy. You hear it in työvimma: a spell of work where everything flows and the hours slip by. It also happens to start with Vim.

What is underneath?

Firefox {{firefox_major}}, on the release channel, so you get Mozilla's engine and its add-on ecosystem. Vimma is built with Surfer, the toolchain behind Zen Browser. Vimma's code lives in its own files, with small patches to Firefox. Sites see Firefox's user agent byte for byte, and add-ons see Firefox's version number, so the web treats Vimma as Firefox.

What is the licence?

MPL-2.0, like Firefox. This website is MPL-2.0 too, its text and the logo included.

Where is the source?

On GitHub, at github.com/vimma-browser/vimma, public since 10 October 2026. The releases for Linux and macOS, the issue tracker and the specification behind each feature are there too.

Does this site track me?

No. It sets no cookies, runs no analytics and loads no fonts, scripts or images from other servers. The site's own keys (press ?) store one setting in your browser's local storage: whether they are on.

Accessibility

Vimma's own parts, from the status bar and the ctrl+b ? overlay to the pickers, panels and command line, work with a screen reader (Orca on Linux) on top of Firefox's own support. Each overlay, picker, panel and prompt takes focus when it opens and gives it back when it closes. The status bar never announces titles or URLs as they change, all text Vimma draws reaches WCAG AA contrast in the built-in themes, nothing in Vimma's UI animates, and any chord can be remapped to a single key in config.toml. The user guide's Accessibility section says what each part tells a screen reader.
