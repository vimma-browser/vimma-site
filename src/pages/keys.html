Keys

Vimma's default keymap, {{keys_total}} actions. It comes from the same table as Vimma's own ctrl+b ? overlay (docs/bindings.md at {{keys_commit}}), so the two agree. These are only defaults: every key is yours.

  • ctrl+b is the prefix, tmux's default: press it, let go, then press the next key. ctrl+b v splits right.
  • Bare keys such as j or f work in normal mode; in a text field you are in insert, and they type.
  • A tag such as qhelp means the key works only in that mode. space is the leader key, free for bindings of your own.
  • Every action has a name: remap it in config.toml (below), or run it from the : line.
  • New to all this? The docs walk through the keys in order.

every key is yours

Every binding below can be remapped, and so can the ctrl+b prefix and the space leader (leader under [modal]). Put the action's name and your keys in ~/.config/vimma/config.toml; Vimma picks the file up within two seconds of a save.

# ~/.config/vimma/config.toml
[keys]
prefix = "ctrl+a"         # the prefix, as tmux users often remap it
new_tab = ["prefix+t"]    # any action, any keys
