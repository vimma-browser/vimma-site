Install

the honest version

There are no binaries yet. Vimma is pre-alpha, and today you build it from source. Linux x86_64 is the only platform it is built and tested on.

The source repository is not public yet; it opens soon. These are the steps for when it does.

Requirements

  • Linux x86_64.
  • About 35 GB of free disk: the Firefox source and full build take 27 GB, the compiler cache 6.8 GB, Mozilla's toolchains 3.1 GB and the source download 0.8 GB.
  • Node.js 20 or later, Python 3, git.
  • Time: the first full build took 39 minutes on a 16-thread Ryzen with 58 GB of RAM, after a 12.5-minute source download.

Build

$ npm ci                  # dev tools, including Surfer
$ npx surfer download     # Firefox source into engine/
$ npx surfer bootstrap    # Mozilla's toolchains into ~/.mozbuild (once)
$ npm run import          # apply Vimma's files and patches
$ npx surfer build        # full build

Run

$ npm start               # your build, with its own profile
$ npm start -- --fresh    # a throwaway profile instead

npm start runs Vimma with a profile of its own (~/.cache/vimma-dev-profile), so it never touches your Firefox profile. Then press ctrl+b ? to see every binding.

After a git pull, run npm run import and npx surfer build again. Vimma has no updater.

Planned packages

For a later milestone (M6), not released: a tarball, an AppImage, a .deb and an AUR vimma-bin package for Linux x86_64, each with checksums, an SBOM and signatures. Releases wait until Vimma has been daily-driven for a while.
