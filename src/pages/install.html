Vimma {{version}} · Linux x86_64 · macOS

Install

Vimma {{version}}, on Firefox {{firefox}}, is released for Linux x86_64 and for macOS on Apple Silicon (M1 or later). There is no build for Intel Macs or Windows.

Arch Linux

Run as your normal user, from any directory. The same command installs and updates:

$ {{arch_install}}

It builds in ~/.cache/vimma-build, which you can delete at any time: it downloads the release's PKGBUILD for the vimma-bin package, which installs Vimma to /opt/vimma with vimma on your PATH, a desktop entry and icons. makepkg -si asks for your password to install the package and refuses to run as root. To update, run the same command again. sudo pacman -R vimma-bin removes Vimma; your profile stays in your home directory.

Other distributions

The latest release has, for Linux x86_64:

  • a .deb for Debian 12+ and Ubuntu 22.04+: sudo apt install ./{{deb}}
  • an .rpm for Fedora and openSUSE: sudo dnf install ./{{rpm}}, or sudo zypper install --allow-unsigned-rpm ./{{rpm}} (the package has no OpenPGP signature; the release's signed SHA256SUMS vouches for it)
  • an AppImage, {{appimage}}: make it executable and run it; it updates itself
  • a tarball, {{tarball}}: unpack it and run vimma/vimma

Next to them are SHA256SUMS, an SBOM and cosign signatures. Installing, in the guide, explains how to check them.

macOS

{{dmg_note}}

For Macs with Apple Silicon. With Homebrew, install the cask from Vimma's own tap:

$ brew install --cask vimma-browser/tap/vimma

Homebrew checks the download against the checksum the cask pins, puts Vimma in Applications and vimma on your PATH. brew upgrade --cask vimma updates it, brew uninstall --cask vimma removes it and keeps your profile, and brew uninstall --zap --cask vimma removes your profiles, caches and preferences as well; your ~/.config/vimma/ stays.

Without Homebrew, download {{dmg}} from the Vimma {{dmg_version}} release, open it and drag Vimma into Applications. Its checksum is in SHA256SUMS-macos, signed like the Linux files.

Vimma is signed with its Apple Developer ID and notarised by Apple, so it opens like any other app: the first time, macOS only asks whether to open an app downloaded from the internet.

On a Mac, passkeys do not work yet, and your profile lives in ~/Library/Application Support/Vimma/.

Updating

Since 0.1.2, Vimma checks for a new release every 12 hours, or at once with :update. When one is out, the status bar shows ⇡ and its version (in red for a security release), and :update shows the command for how you installed Vimma; each update file is checked with SHA-512. Vimma only tells you, except as an AppImage, which replaces its own file with the new release and runs it from the next start. Otherwise, run that command: on Arch Linux, the command above again; otherwise, install the newer .deb, .rpm or tarball over the old one (there is no Vimma repository for apt, dnf or zypper, so a system upgrade does not update it). A 0.1.1 install has no update check, so update it this way by hand once.

On a Mac, the notice and :update work the same way: run brew upgrade --cask vimma, or install the newer .dmg over the old one.

Build from source

To build Vimma yourself, clone https://github.com/vimma-browser/vimma and follow the steps below. A source build has Safe Browsing off unless you add your own Google key: see below.

Requirements

  • Linux x86_64, for the macOS build too: it is cross-compiled on Linux (CONTRIBUTING.md has the steps).
  • About 35 GB of free disk: the Firefox source and full build take 27 GB, the compiler cache 6.8 GB, Mozilla's toolchains 3.1 GB and the source download 0.8 GB.
  • Node.js 20 or later, Python 3, git.
  • Time: about 40 minutes for the first full build on a 16-thread machine, plus the Firefox source download.

Build

$ git clone https://github.com/vimma-browser/vimma.git && cd vimma
$ npm ci                  # dev tools, including Surfer
$ npx surfer download     # Firefox source into engine/
$ npx surfer bootstrap    # Mozilla's toolchains into ~/.mozbuild (once)
$ npm run import          # apply Vimma's files and patches
$ npx surfer build        # full build

Google Safe Browsing

Google Safe Browsing (phishing and malware protection) needs an API key, which is not in the repository. A build without one works, but Safe Browsing is off. To turn it on, get a free key from Google and save it as ~/.config/vimma/keys/safebrowsing before building (the runbook has the steps).

Run

$ npm start               # your build, with its own profile
$ npm start -- --fresh    # a throwaway profile instead

npm start runs Vimma with a profile of its own (~/.cache/vimma-dev-profile), so your Firefox profile is never touched. Press ctrl+b ? to see every binding.

To update a source build, pull the latest main, then run npm run import and npx surfer build again.
